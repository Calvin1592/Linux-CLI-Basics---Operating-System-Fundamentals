# Linux-CLI-Basics---Operating-System-Fundamentals

In this lab, I practiced fundamental Bash commands used to navigate and manage a Linux system through the terminal.

I then worked with directory navigation using cd, including moving up the directory tree and returning to my home directory. I used ls, ls -l, and ls -la to inspect directory contents and understand file permissions, ownership, and hidden files.

Next, I created and managed files and directories. I used mkdir to create directories and touch to generate files. With echo and output redirection (> and >>), I added and modified file content. I verified file contents using cat and checked file types with the file command.

I practiced file operations such as copying (cp), moving and renaming (mv), and deleting (rm -i) while observing how these actions affect the filesystem. I also explored recursive listing with ls -R to view directory structures.

To handle large files, I used more and less for efficient viewing and navigation. I generated a large file using a pipeline that combined /dev/urandom, base64, and head, demonstrating how powerful command chaining can be.

I then focused on searching and filtering data. Using find, I located files by name, and with grep, I searched file contents for specific text. I combined commands with pipes (|) to sort (sort), remove duplicates (uniq), and count data (wc), reinforcing how small tools can be chained together to perform complex tasks.

Finally, I applied these concepts to analyze file ownership and counts using ls, grep, and wc. I completed the lab by running a validation script to confirm all tasks were performed correctly.

Overall, this lab strengthened my understanding of Linux command-line fundamentals, file system navigation, file manipulation, and the power of command chaining through pipes.
